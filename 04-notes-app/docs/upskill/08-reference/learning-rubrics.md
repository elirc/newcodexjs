# Learning Rubrics

Project: **Notes App** (`04-notes-app`)

| Level | Observable Behavior |
| --- | --- |
| Junior | Runs the app, names layers, traces one flow, makes small safe changes. |
| Mid-level | Designs cross-layer changes, adds tests, preserves contracts, debugs systematically. |
| Senior | Critiques architecture, names tradeoffs, reduces blast radius, writes migration and rollback plans. |

Self-check: can you explain markdown notes, folders, tags, searchable knowledge capture using concrete files, not generic stack terms?
